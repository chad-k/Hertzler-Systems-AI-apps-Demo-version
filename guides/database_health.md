## What AI Database Health Assistant does

Understand database maintenance and performance findings through a simulated SQL Server health check.

### A simple example

A database supports applications by storing and retrieving information. As it grows, slow queries, storage pressure, blocking, or maintenance gaps may affect response times. The demo shows how these issues can be organized and explained.

### What you can do in this free demo

Explore the demo database sections and the available findings, charts, and recommendations. Use the question box with topics shown in the app. Compare detailed evidence with the summary before deciding what you would investigate first.

The data is synthetic and already included. You can explore the existing filters, settings, charts, and downloads without supplying company files. Changes affect your demonstration session, not production equipment or records.

### How to understand the results

Storage findings concern space and growth. Index findings concern structures that help retrieve rows. Blocking means one task is waiting for another. Query Store-style history shows query performance over time. Scores summarize the demo’s rules; they are not a universal SQL Server rating.

### What the results cannot tell you

Everything shown here is generated example data. This version has no live database connection controls and cannot inspect or change your database. The question assistant uses supported patterns and topics; it is not a general-purpose AI model. Recommendations need a DBA’s review, because a change that helps one workload can hurt another.

### What a version customized for you would need

Your SQL Server environment, read-only permissions appropriate to agreed diagnostics, workload priorities, and maintenance requirements. Any future production connector would require separate configuration and validation; it is not included in the public demo.
