## What Manufacturing Copilot does

Explore manufacturing measurements using plain-language requests and familiar quality charts.

### A simple example

Instead of manually choosing every filter, you can type a supported request about a part, machine, or quality characteristic. The demo translates supported words into an analysis of its sample measurement data.

### What you can do in this free demo

Start with the built-in data and try the example requests shown in the app. Type a request or use the existing voice control where your browser supports it. Review the interpreted selection and chart before relying on the answer; rephrase or use the available controls if the request is unclear.

The data is synthetic and already included. You can explore the existing filters, settings, charts, and downloads without supplying company files. Changes affect your demonstration session, not production equipment or records.

### How to understand the results

SPC charts show measurements over time and highlight process behavior. Capability comparisons use measures such as Cpk to describe how process spread and centering compare with specifications. Dashboard views bring multiple summaries together. The example schema includes Timestamp, Part, Machine, Characteristic, Value, LSL, Target, and USL.

### What the results cannot tell you

This is a deterministic command parser, not an unrestricted conversational AI. It understands supported topics and wording, not every question. Voice recognition depends on the component/browser service and is separate from the local text parser. Capability estimates need appropriate, stable data; a large Cpk alone does not prove a process is controlled. The demo does not control manufacturing equipment.
